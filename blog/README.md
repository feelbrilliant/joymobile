# 조이모바일 블로그 자동화

네이버 블로그 글을 주제 선정부터 스마트에디터 입력까지 자동으로 준비하고,
발행 버튼은 사람이 직접 누르는 도구입니다.

## 현재 상태

PHASE 0 (기반 자료) 완료. 프로그램 코드는 PHASE 1부터 추가합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `prompts/system.md` | 글 작성 규칙 전체 (역할, 운영 방향, 고객층, 문체, 금지사항, 출력 형식) |
| `prompts/user.md` | 글마다 바뀌는 입력값 (키워드, 제목, 권장 유형, 중심 고객층) |
| `data/plans.json` | 요금제 정보. 가격·제공량의 유일한 기준 |
| `data/topics.csv` | 주제 목록. 키워드와 제목, 권장 유형, 대상 고객, 사용 기록 |
| `data/rules.json` | 초안 자동 검수 기준 (글자 수, 키워드 횟수, 금지 표현, URL·전화번호 등) |

## 관리 방법

- **요금제가 바뀌면** `data/plans.json` 만 고칩니다. 프롬프트의 `{{요금제_정보}}` 자리에 이 파일 내용이 자동으로 들어갑니다.
- **새 주제를 추가할 때** `data/topics.csv` 에 한 줄 추가합니다. 제목은 그대로 발행되므로 확정된 제목만 `상태`를 `사용가능`으로 둡니다.
- `상태` 값
  - `검토필요`: 제목 확인 전. 자동 선정에서 제외
  - `사용가능`: 자동 선정 대상
  - `사용완료`: 이미 글을 쓴 주제. `사용일`에 날짜 기록
- 글 작성 규칙을 바꿀 때는 `prompts/system.md` 를 고치고, 프로그램으로 확인할 수 있는 규칙이면 `data/rules.json` 에도 반영합니다.
