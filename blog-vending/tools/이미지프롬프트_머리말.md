# 조이모바일 블로그 이미지 {N}장 순서대로 생성 요청

첨부한 이미지는 조이모바일 캐릭터 원본(조이모바일 프로필.png)이다

아래 [공통 조건]을 모든 이미지에 적용하고 `## 01`부터 `## {NN}`까지 **각각 별도의 1:1 정사각형 이미지**로 만들어줘

진행 방식

- 지금은 **01번 한 장만** 생성
- 내가 "다음"이라고 입력하면 그다음 번호 한 장만 생성
- 내가 "다시"라고 입력하면 방금 번호를 같은 프롬프트로 다시 생성
- 여러 장을 한 이미지에 합치는 콜라주 · 그리드 금지
- 매 장마다 생성 전에 첨부한 캐릭터 원본을 다시 보고 외형 · 얼굴 화면 비율 · 색 · 팔다리 길이를 원본과 똑같이 맞출 것
- 이전에 만든 이미지의 캐릭터를 참고 기준으로 쓰지 말고 항상 첨부 원본만 기준으로 삼을 것
- 이미지마다 위에 번호만 짧게 적고 다른 설명은 생략
