# 블로그 포스팅 반자동 흐름

```
ㄱㄱ ─▶ ① 글 + 이미지 프롬프트 (Claude, 자동)
     ─▶ ② 이미지 생성 (ChatGPT: 원본 첨부 + 파일 통째로 1번 붙여넣기 → "다음" 반복)
     ─▶ ③ 이미지 검수 (Claude, 자동)
     ─▶ ④ 자동 점검 + 미리보기 (스크립트)
     ─▶ ⑤ 네이버 임시저장 (스크립트, 사용자 PC)
     ─▶ ⑥ 최종 검수 + 발행 (사람)
```

## 포스트 폴더

```
posts/2026-10-04_김포_업무용세컨번호/
    본문.txt           첫 줄 제목, 섹션은 ----- 줄로 구분
    이미지프롬프트.md   ## 01 썸네일, ## 02 ... 순서
    images/            01.png ~ 10.png (프롬프트 번호와 같게)
```

k번째 이미지는 k번째 섹션 맨 앞에 자동으로 들어갑니다 (01 썸네일 → 도입부).

## ② 이미지 생성 (ChatGPT, 붙여넣기 1번)

1. ChatGPT 새 대화에 `joymobile-profile.png`를 첨부하고, `이미지프롬프트.md` **파일 전체**를 한 번에 붙여넣기
2. 01번이 나오면 확인하고 `다음` 입력 → 마지막 번호까지 반복 (이상한 컷은 `다시`)
3. 뒤로 갈수록 캐릭터가 흐트러지면 새 대화를 열어 원본 첨부 후 해당 번호만 붙여넣기
4. 받은 이미지를 Claude 세션에 한꺼번에 업로드 (이름은 상관없음. Claude가 내용을 보고 01.png… 순서로 맞춰요)

## ③ 이미지 검수

Claude에게 "이미지 검수"라고 하면 각 이미지를 직접 열어 팔·발 개수, 얼굴 비율, 한국어 오타, 숫자, 브랜드 문구를 확인하고 문제 컷의 수정 프롬프트를 줍니다.

## ④ 자동 점검 + 미리보기

```
cd blog-vending/tools
python check_post.py ../posts/<폴더>      # 금지 표현·오타·브랜드 문구·시간·이미지 수
python build_preview.py ../posts/<폴더>   # <폴더>/preview.html 생성 → 브라우저로 열어 확인
```

## ⑤ 네이버 임시저장 (사용자 PC)

처음 한 번 설치 (Windows PowerShell 기준, Python 3.10 이상 필요):

```
pip install playwright
playwright install chrome
```

실행:

```
cd blog-vending/tools
python naver_draft.py ../posts/<폴더> --dry-run                    # 입력 순서만 확인
python naver_draft.py ../posts/<폴더> --blog-id 내아이디 --no-save   # 첫 시험: 입력만
python naver_draft.py ../posts/<폴더> --blog-id 내아이디            # 입력 + 임시저장
```

- 처음 실행하면 열린 크롬 창에서 직접 로그인하세요. 이후에는 로그인 상태가 유지됩니다(이 PC의 `~/.joymobile_naver_profile`).
- 스크립트는 **'저장'(임시저장)만 누르고 '발행'은 절대 누르지 않습니다.**
- 아직 실제 네이버 화면으로 시험하지 못했습니다(클라우드 환경에서 네이버 접속이 막혀 있음). 첫 실행은 `--no-save`로 하고, 멈추거나 잘못 입력되면 화면과 오류 메시지를 Claude에게 보내주세요. `SELECTORS` 값을 맞춰 고칩니다.
- 자동 입력은 네이버 운영정책상 제재 위험이 있습니다. 하루 여러 편을 연속으로 돌리지 말고, 반드시 사람이 검수한 뒤 발행하세요.

## ⑥ 발행

네이버 블로그 → 임시저장 글 불러오기 → 줄바꿈·이미지 위치·태그 확인 → 발행
