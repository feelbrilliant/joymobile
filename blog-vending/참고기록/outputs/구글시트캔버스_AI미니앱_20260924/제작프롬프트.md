# 구글시트 캔버스 AI 미니앱 이미지 제작 기록

- 제작 방식: OpenAI 기본 이미지 생성 도구
- 규격: 1254 × 1254px, 1:1 정사각형 PNG
- 스타일: 깔끔하고 현대적인 2D IT 정보 일러스트
- 캐릭터: 조이모바일 원본 캐릭터 1명만 사용
- 신체 구조: 팔 2개, 손 2개, 다리 2개, 발 2개
- 인터페이스: 실제 Google Sheets·Gemini 화면을 복제하지 않은 generic 업무 UI
- 제외: 외부 URL, QR코드, 워터마크, 실제 회사·고객·재무 데이터, 실사, 3D

## 제작 이미지와 핵심 프롬프트

1. `00_썸네일.png` — **구글시트 캔버스 / AI 미니앱 만들기**. 스프레드시트가 자연어 프롬프트를 거쳐 칸반보드·KPI 대시보드·타임라인으로 변환되는 장면.
2. `01_스프레드시트를미니앱으로.png` — 기존 수작업 흐름과 `Sheets canvas / 자연어 → 대화형 미니앱` 비교.
3. `02_코딩없이미니앱생성.png` — `기존 시트 데이터 → Gemini에게 원하는 화면 설명 → 대화형 미니앱 생성` 3단계.
4. `03_시트에서칸반보드.png` — 시트의 업무명·담당자·상태·마감일·우선순위가 칸반보드로 변환되고 양방향 반영되는 흐름.
5. `04_매출데이터대시보드.png` — 긴 매출표가 총매출·월별 추이·고객 유형별 실적·전환율·성과 변화 대시보드로 변환.
6. `05_예산표시뮬레이션.png` — 광고비·인건비·매출 가정을 조절하는 대화형 예산 시뮬레이션.
7. `06_일정데이터타임라인.png` — 일정 데이터가 타임라인·캘린더·진행표로 변환되고 카드 이동이 원본에 반영되는 장면.
8. `07_업무우선순위매트릭스.png` — 필요한 작업량과 예상 효과를 축으로 한 2×2 우선순위 매트릭스.
9. `08_아이디어협업보드.png` — 아이디어 행 데이터가 주제별 그룹화·투표·담당자·실행 항목이 있는 협업 보드로 변환.
10. `09_Sheets_canvas_사용방법.png` — Google Sheets 실행부터 Gemini에게 화면을 설명하는 과정까지 5단계.
11. `10_지원계정확인.png` — 지원 요금제 목록과 무료 계정에서 기능이 보이지 않을 수 있다는 안내.
12. `11_활용분야.png` — 하나의 시트가 프로젝트·마케팅·매출·예산·콘텐츠·고객·우선순위·회의 업무 화면으로 확장.
13. `12_FAQ.png` — 코딩 필요 여부, 시트 연동, 무료 계정, 생성 가능한 화면을 설명하는 FAQ.
14. `13_핵심정리.png` — 기존 데이터가 Gemini 자연어 요청을 거쳐 여섯 가지 대화형 업무도구로 확장되는 총정리.
