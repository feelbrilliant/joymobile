# Meta One · AI 유료 구독 이미지 제작 기록

## 공통 제작 기준

- 블로그 첨부용 1:1 정사각형, 1254×1254px
- 조이모바일 원본 캐릭터 참조 이미지 사용
- 각 이미지에 조이모바일 캐릭터 1명만 배치
- 캐릭터는 팔 2개·손 2개·다리 2개·발 2개로 고정하고 신체 연결 상태 확인
- 공식 Meta 광고나 Instagram·Facebook·WhatsApp 화면을 정밀 복제하지 않은 일반 SNS·AI 인터페이스 사용
- 실제 계정·DM·고객 정보, 외부 URL, QR코드, 워터마크 제외
- 기본 기능 무료 유지, 선택형 구독, 계정별 순차 제공 등의 조건을 유지
- 제공된 글로벌 시작 가격만 사용하고 Expert·Max 가격은 임의 생성하지 않음
