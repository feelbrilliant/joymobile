# 동작구 선불폰 · 개인회생 중 개통 확인 이미지 제작 기록

## 공통 제작 기준

- 블로그 첨부용 1:1 정사각형, 1254×1254px
- 조이모바일 원본 캐릭터 참조 이미지 사용
- 이미지마다 조이모바일 캐릭터 1명만 등장
- 팔 2개·손 2개·다리 2개·발 2개와 신체 연결 상태 확인
- 개인회생·채무조정 상황을 자극적이거나 낙인적인 이미지로 표현하지 않음
- 개통 가능 여부는 여러 조건에 따라 달라진다는 원문의 의미 유지
- 실제 사건번호·채무금액·신분증·전화번호 예시·인증번호·QR코드 제외
- 무조건 개통, 100% 개통, 당일개통 보장 등의 단정 표현 제외
