# 관악구 선불폰 번호이동 이미지 제작 기록

- 규격: 1254 × 1254px, 1:1 정사각형 PNG
- 스타일: 밝고 깔끔한 2D 정보형 일러스트
- 캐릭터: 조이모바일 원본 캐릭터 1명만 사용
- 공통 검수: 팔 2개, 손 2개, 다리 2개, 발 2개 / 중복 캐릭터·떠 있는 신체 없음
- 개인정보, 실제 전화번호 예시, QR코드, 외부 URL, 과장·보장 문구 제외

5. `04_번호이동미납관계.png` — 번호이동과 미납의 관계

8. `07_기존번호유지.png` — 기존 번호 유지

## 수정 사항

`04_번호이동미납관계.png`는 다른 상태확인 컷과 혼동되지 않도록 다시 제작했습니다. 왼쪽은 `요금 먼저 충전 → 서비스 이용`, 오른쪽은 `현재 번호 상태·미납 여부·정지 여부·이동 가능 조건`으로 분리했습니다.

세부 원문은 같은 폴더의 `원본프롬프트.txt`에 보관했습니다.
