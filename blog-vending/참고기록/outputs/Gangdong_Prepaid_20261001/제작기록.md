# 강동구 선불폰 블로그 이미지 8컷

- 제작 방식: 내장 이미지 생성 도구
- 입력: `원본프롬프트.txt` 및 조이모바일 원본 캐릭터 참고 이미지
- 규격: 1:1 정사각형 PNG 8개

## 최종 수정 프롬프트 요약

- 썸네일: 큰 제목을 정확히 두 줄 `강동구 선불폰` / `정지 후 새 번호 준비`로 정리.
- 준비물 컷: 신분증 아이콘에서 얼굴·개인정보를 제거한 빈 generic 카드로 수정.
- 개통순서 컷: 구불구불한 길 대신 위→아래의 `선택 → 신청 → 승인 → 사용` 네 구간으로 재구성. 단계 번호 1~10은 각 한 번씩 표시하고 구간 제목의 중복 번호를 제거. 신규가입 시간 `08:00 ~ 21:50`과 마감 직전 신청 주의 문구 유지.

## 검수 메모

- 정지·미납 이력이 있어도 개통을 보장하지 않는 조건부 표현을 유지했습니다.
- 기존 번호 복구와 새로운 번호의 신규가입을 별개 절차로 구분했습니다.
- 요금제의 `39,600원 / 10.3GB / 소진 후 최대 3Mbps`는 원본 프롬프트 값을 사용했습니다. 실제 신청 전 최신 요금·개통 가능 시간을 다시 확인해야 합니다.
