# 자급제폰 개통방법 블로그 이미지

대표 썸네일 1장과 본문 10장입니다. 파일명 번호는 글의 순서이며 이미지 제목의 소제목 번호는 제거했습니다.

내장 이미지 생성 기능(image_gen)으로 제작했습니다. 원본 캐릭터 참고: 조이모바일 프로필.png.

수정 반영: 알뜰폰 안내의 발 가림, 알뜰폰 이용 패턴의 상황 문구, 선불폰 이용 패턴의 팔 부착 위치. 선불폰 이용 패턴은 팔이 흰 얼굴 화면이 아닌 파란 몸체 바깥쪽 옆면에서 이어지는 수정본입니다.
