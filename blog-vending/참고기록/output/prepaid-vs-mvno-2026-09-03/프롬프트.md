# 선불폰 VS 알뜰폰 이미지 프롬프트 세트

## 공통 캐릭터 기준

- 조이모바일 프로필 이미지를 유일한 캐릭터 레퍼런스로 사용한다.
- 세로로 긴 스마트폰 실루엣, 흰색 얼굴 화면 비율, 스피커 슬롯, 얼굴 요소, 외곽선과 본체 색상 `#7CAEFD`를 그대로 유지한다.
- 짧은 파란 팔 2개, 흰 장갑 손 2개, 짧은 파란 다리 2개, 둥근 파란 신발 2개만 표현한다.
- 팔은 반드시 파란 외곽 프레임에서 시작하고, 얼굴 화면에서 나오지 않는다.
- 파란 다리와 파란 신발은 흰색 발목·양말·링 없이 직접 연결한다.
- 손발 누락, 추가, 융합, 부유, 중복을 금지한다.
- 일반 스마트폰, 유심, 카드, 청구서, 아이콘에는 얼굴이나 팔다리를 추가하지 않는다.
- 정면 차렷, 엄지척, 제목 가리키기, 동일 포즈 반복을 피하고 장면에 맞는 자연스러운 행동을 사용한다.
- 자연색과 중립색을 다양하게 사용하고, 화면 전체 블루톤과 반복 카드 레이아웃을 피한다.
- 깨진 한글, 실제 개인정보, 실제 인증번호, 스캔 가능한 QR코드, 워터마크, 과장된 보장 문구를 넣지 않는다.

## 00 썸네일

메인 제목은 `선불폰 VS 알뜰폰`과 `나에게 맞는 선택은?` 두 줄만 크게 표시한다. 왼쪽은 알뜰폰을 월 요금 청구서·데이터 요금제·달력·스마트폰으로, 오른쪽은 선불폰을 충전 게이지·유심·업무용·세컨폰으로 보여준다. 중앙 캐릭터는 스마트폰 화면과 사용 카드를 자연스럽게 비교한다. 어느 한쪽도 더 우수하게 추천하지 않는다. 하단에 `조이모바일.com`과 `개통센터 대표번호 / 010-4486-2532`를 정확히 표기한다.

## 01 선불폰과 알뜰폰은 무엇이 다를까요

왼쪽 알뜰폰 흐름은 `대부분 후불 방식`, `서비스 이용 → 월 사용량 확인 → 나중에 요금 납부`, `먼저 사용 → 이후 납부`로 표시한다. 오른쪽 선불폰 흐름은 `요금 먼저 충전 → 서비스 이용 → 필요 시 다시 충전`, `먼저 충전 → 이후 사용`으로 표시한다. 중앙에는 `가장 큰 차이`, `요금을 언제 내느냐`를 강조한다.

## 02 알뜰폰의 장점

`요금제 다양`, `무제한 요금제 선택 가능`, `약정 없는 상품이 많음`, `기존 통신망 이용`을 크게 표시한다. 하단에는 `장기간 사용할 휴대폰`, `다양한 요금제 비교`를 배치한다. 캐릭터는 소파나 의자에 옆으로 앉아 요금제 카드를 넘겨본다.

## 03 선불폰의 장점

중앙에 `선불폰`, `먼저 충전 → 필요한 만큼 사용`을 두고, 주변에 `약정 부담 적음`, `요금 관리`, `세컨폰`, `업무용 번호`, `현재 상황에 따라`, `개통 가능 여부 확인`을 배치한다. 100% 개통이나 무조건 개통 같은 보장 표현은 금지한다.

## 04 어떤 사람이 알뜰폰이 잘 맞을까요

`매달 일정한 요금 납부`, `장기간 같은 번호 사용`, `다양한 요금제 비교`, `저렴한 요금제 탐색`을 보여준다. 하단에는 `장기간 이용`, `요금제 선택 폭`, `월 요금 관리`를 표시한다. 가격 숫자는 넣지 않는다.

## 05 어떤 사람이 선불폰이 잘 맞을까요

`업무용 번호`, `배달용 휴대폰`, `세컨폰`, `요금 직접 관리`, `개통 가능 여부 확인`을 지도 경로·위치 핀·업무 연락·사용량 게이지와 함께 표현한다. 캐릭터는 개인용 스마트폰과 책상 위 업무용 스마트폰을 비교한다.

## 06 요금은 얼마나 차이가 날까요

중앙 흐름은 `가격만 비교 X → 내 사용량 먼저 확인`으로 구성한다. `데이터`, `통화`, `문자`, `사용 기간`을 확인한 뒤 요금제를 선택하는 흐름을 보여준다. 하단에는 `가장 싼 요금제보다`, `나에게 맞는 요금제`를 강조하고 실제 가격·요금제명·할인율은 넣지 않는다.

## 07 자급제폰에서도 사용할 수 있을까요

중앙 `자급제폰`에서 왼쪽 `알뜰폰 / 후불 요금제`, 오른쪽 `선불폰 / 충전형 요금`으로 갈라지는 흐름을 표현한다. 하단에는 `기존 유심`, `새로운 유심`, `자급제폰에서도 알뜰폰 · 선불폰 사용 가능`을 표시한다. 브랜드와 모델명은 넣지 않는다.

## 08 현명한 소비자가 되는 방법

`내 사용패턴 CHECK` 아래에 `평균 데이터 사용량`, `통화량`, `사용 기간`, `업무용 여부`, `세컨폰 필요 여부`, `약정 여부`를 체크리스트로 배치한다. 화살표 다음에 `나에게 맞는 통신 서비스 선택`을 크게 표시한다.

## 09 선불폰 VS 알뜰폰 FAQ

1. `선불폰이 더 저렴한가요?` — `요금제 · 사용량에 따라 달라질 수 있음`
2. `자급제폰에서도 둘 다 가능?` — `알뜰폰 · 선불폰 모두 사용 가능`
3. `업무용으로 사용할 수 있나요?` — `목적에 맞는 요금제로 활용 가능`
4. `어떤 선택이 더 좋을까요?` — `사용 기간 · 목적 · 요금 관리 방식에 맞춰 선택`

하단에 `조이모바일.com`과 `개통센터 대표번호 / 010-4486-2532`를 정확히 표기한다.

## 10 선불폰 VS 알뜰폰 정리

알뜰폰 영역에는 `대부분 후불`, `다양한 요금제`, `장기간 이용`, `정기적인 월 요금`을 표시한다. 선불폰 영역에는 `먼저 충전`, `요금 직접 관리`, `업무용 · 세컨폰`, `사용 목적에 맞게 활용`을 표시한다. 중앙 결론은 `무조건 어느 쪽이 더 좋다 X → 내 사용 패턴과 목적에 맞게 선택`이다. 선택 기준은 `데이터`, `통화량`, `사용 기간`, `업무용 여부`, `세컨폰`, `약정`이다. 하단에 지정 브랜드 문구 두 줄을 정확히 표기한다.
