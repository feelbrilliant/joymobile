# IMEI 조회 블로그 이미지

대표 썸네일 1장과 본문 11장입니다. 파일명 번호는 사용 순서이며 이미지 제목의 소제목 번호는 제거했습니다.

생성 방식: 내장 이미지 생성 기능(image_gen).
원본 캐릭터 참고 이미지: 조이모바일 프로필.png.
실제 IMEI 및 시리얼번호는 사용하지 않고 마스킹했습니다.
최종 검수에서 보안 장의 가려진 손, 비교 장의 엄지척, 전화 앱 안내의 팔레트를 수정했습니다.
