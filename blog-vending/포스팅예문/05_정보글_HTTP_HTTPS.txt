HTTP와 HTTPS는 무엇이 다를까요❓

웹사이트 주소를 보면 보통

http://

또는

https://

로 시작합니다

HTTPS의 S는 Secure를 의미해요 🔒

HTTPS에서는 사용자와 웹사이트 사이에서 전송되는 정보가 암호화됩니다

반면 HTTP는 암호화되지 않은 방식이기 때문에 같은 네트워크를 사용하는 공격자 등이 통신 내용을 엿보거나 변조할 위험이 상대적으로 높습니다

-----

Chrome 154부터 무엇이 달라졌을까요❓

기존 Chrome에서도 HTTP 사이트에는 주소창에 안전하지 않다는 표시가 나타났습니다

하지만 Chrome 154부터는 한 단계 더 강해졌어요

보안이 적용되지 않은 공개 HTTP 사이트에 처음 접속하면 Chrome이 바로 페이지를 열기보다 먼저 경고 화면을 표시합니다 ⚠️

사용자가 내용을 확인한 뒤 접속 여부를 결정하도록 바뀐 것입니다

즉 HTTP 사이트가 완전히 차단된 것은 아니지만 아무런 확인 없이 바로 접속하는 방식은 줄어들게 됩니다

-----

HTTP 사이트는 무조건 위험한 걸까요❓

HTTP라는 이유만으로 해당 사이트가 악성 사이트라는 뜻은 아닙니다

오래된 개인 홈페이지나 일부 장비 설정 페이지처럼 아직 HTTPS가 적용되지 않은 사이트도 있어요

하지만 HTTP 페이지에서는 중요한 개인정보를 입력하지 않는 것이 좋습니다

특히

아이디와 비밀번호

신용카드 정보

주민등록번호

은행 정보

개인 연락처

등을 입력하라는 페이지라면 한 번 더 확인해주세요 🚨

-----

HTTPS면 무조건 안전할까요❓

이 부분도 주의해야 합니다

HTTPS는 연결 과정이 암호화돼 있다는 의미이지 해당 사이트 자체가 무조건 정상이라는 뜻은 아닙니다

피싱 사이트도 HTTPS 인증서를 사용할 수 있어요

따라서 로그인이나 결제를 하기 전에는

주소가 정확한지

이상한 도메인은 아닌지

공식 사이트가 맞는지

를 함께 확인하는 것이 중요합니다 🔍

자물쇠나 HTTPS 표시 하나만 보고 사이트를 완전히 신뢰해서는 안 됩니다

-----

갑자기 경고가 뜬다면 어떻게 해야 할까요❓

평소 이용하지 않던 사이트에서 경고가 나타났다면 우선 주소를 다시 확인해주세요

광고나 문자메시지 링크를 통해 접속했다면 특히 주의하는 것이 좋습니다

꼭 필요한 사이트라면 공식 홈페이지 주소를 검색해서 다시 접속해보세요

로그인이나 결제가 필요한 페이지라면 HTTPS가 적용된 공식 주소를 이용하는 편이 안전합니다 👍

FAQ

Q. HTTP 사이트는 이제 Chrome에서 접속할 수 없나요❓

A. 완전히 차단되는 것은 아닙니다

Chrome이 먼저 보안 경고를 보여주고 사용자가 확인한 뒤 접속 여부를 결정하는 방식입니다

━━━━━━━━━━━━━━━━━━━━

Q. HTTPS 사이트라면 개인정보를 입력해도 무조건 안전한가요❓

A. 아닙니다

HTTPS는 연결이 암호화됐다는 의미이며 사이트 자체가 정상인지까지 보장하지는 않습니다

주소와 운영 주체도 함께 확인해주세요

━━━━━━━━━━━━━━━━━━━━

Q. 예전에 잘 들어가던 사이트에서 갑자기 경고가 뜨는 이유는 뭔가요❓

A. 해당 사이트가 아직 HTTP 방식만 사용하고 있고 Chrome의 보안 정책이 강화되면서 경고가 표시되는 경우가 있습니다
